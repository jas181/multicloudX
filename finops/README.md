# FinOps baseline

Every resource receives `application`, `environment`, `owner`, `cost_center`, and `managed_by` metadata. Configure Azure Cost Management budgets, AWS Budgets, and GCP Billing Budgets before applying. The Phase 1 defaults avoid always-on NAT/VPN/compute; review regional storage/logging retention and provider minimum charges. Sample reporting schema: [sample-costs.csv](sample-costs.csv).
